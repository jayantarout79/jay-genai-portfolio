# 📘 Glossary (ML + GenAI)

- **Decision Tree:** Supervised ML model splitting data into rules.
- **Random Forest:** Ensemble of trees reducing overfitting.
- **Precision:** Correct positive predictions / all predicted positives.
- **Recall:** Correct positive predictions / all actual positives.
- **ROC-AUC:** Measures separation ability of classifier.
- **Overfitting:** Model learns noise, fails on new data.
- **Feature Importance:** Score showing which input variables matter most.
- **One-Hot Encoding:** Converting categorical variables into binary vectors.
- **RAG (Retriever Augmented Generation):** LLM answers supported by external documents.
- **FAISS:** Vector database for similarity search.
- **LangChain:** Framework to build LLM apps with tools & memory.
- **Embeddings:** Numeric representation of text capturing meaning.
