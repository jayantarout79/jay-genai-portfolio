# Incident Response Guide

## Definition
An incident is any unplanned event that impacts data availability, accuracy, or timeliness.

## Severity Levels
- Low: Minor delay or partial data impact
- Medium: Multiple consumers affected
- High: Critical dashboards or reports impacted

## Response Steps
1. Acknowledge the incident
2. Assess impact and severity
3. Communicate status to stakeholders
4. Apply fix or workaround
5. Perform post-incident review

## Communication
Incident updates should be shared periodically until resolution.
